<h1 align="center">Countries and Capitals</h1>
O Projeto é um jogo de geração de questionários sobre as capitais de países.

Funcionalidades do projeto:
- Geração de questionário
- Responder o questionário

### Tecnologias utilizadas
- Laravel v12.0
- PHP v8.2

### Instalação das dependências
Abrir o terminal e executar o seguinte comando para instalar as dependências:
```bash
composer update
```

### Geração da chave
```bash
php artisan key:generate
```
